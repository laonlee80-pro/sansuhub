[입력폼] 입력값을 바꾼 뒤 ▶(Calculate)를 누르세요. 폼↔코드 전환: F4.

KDS 측압식 P=Cw·Cc·[7.2+785R/(T+17.8)], 단 30 ≤ P ≤ γc·H.

경험식이라 대괄호는 무차원(R,T 숫자)으로 계산하고 결과에 1kN/m²를 곱한다.

1. 설계 조건

단위중량계수 : Cw = 1.0 

시멘트계수(지연제 없음) : Cc = 1.0 

타설속도(m/h, 숫자) : R = 1.5 

콘크리트 온도(℃, 숫자) : T = 20 

콘크리트 단위중량 : γc = 24  kNm3

벽체 높이 : H = 3.0  m

2. 측압 산정

KDS 측압 : P = Cw · Cc · (7.2 + 785 · RT + 17.8) · 1 kNm2 = 1 · 1 · (7.2 + 785 · 1.520 + 17.8) · 1 kNm2 = 38.350794 kN ∕ m2

최솟값(하한) : Pmin = 30 kNm2

최댓값(액압 한계) : Pmax = γc · H = 24 kN ∕ m3 · 3 m = 72 kN ∕ m2

3. 상·하한 검토 → 설계 측압

설계 측압 : Pdesign = min ( max ( P; Pmin ) ; Pmax )  = min ( max ( 38.350794 kN ∕ m2; 30 kN ∕ m2 ) ; 72 kN ∕ m2 )  = 38.350794 kN ∕ m2

계산값 ≥ 30 kN/m² → 계산값 채택
